# Section Definitions

This file defines the rule categories for cybersecurity dashboard UX best practices. Rules are automatically assigned to sections based on their filename prefix.

---

## 1. Personas (persona)
**Impact:** CRITICAL
**Description:** The two primary audiences — AppSec teams and engineers — their mental models, questions, interaction styles, and how to design for each without compromising the other.

## 2. Information Architecture (ia)
**Impact:** CRITICAL
**Description:** Layered information structure, problem-space organization over tool-based organization, and task-first navigation that mirrors jobs-to-be-done.

## 3. Screen Design (screen)
**Impact:** HIGH
**Description:** Screen-by-screen specifications for the core dashboard surfaces: org overview, engineering home, service detail, vulnerability explorer, and issue detail pages.

## 4. Drill-Down & Navigation (drilldown)
**Impact:** HIGH
**Description:** Consistent, predictable drill-down chains from cards to charts to explorers to detail pages. Pre-applied filters, breadcrumbs, and deep-linking patterns.

## 5. Visual Design (visual)
**Impact:** MEDIUM-HIGH
**Description:** Severity color systems, trend indicators, status badges, empty/loading/error states, and structured density for information-rich security interfaces.

## 6. Interaction Patterns (interaction)
**Impact:** MEDIUM
**Description:** Filter persistence across navigation, inline actions, keyboard shortcuts for power users, notification hierarchy, and saved views.

## 7. Design Checklist (checklist)
**Impact:** MEDIUM
**Description:** Comprehensive verification checklist covering persona clarity, information hierarchy, drill-down integrity, action density, data integrity, and usability benchmarks.
