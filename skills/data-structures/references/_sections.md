# Section Definitions

This file defines the rule categories for optimized data structures. Rules are automatically assigned to sections based on their filename prefix.

---

## 1. Design Method (method)
**Impact:** CRITICAL
**Description:** The systematic approach to choosing or building a data structure — profiling access patterns, matching patterns to structures, evaluating build vs stdlib, and implementing with benchmarks.

## 2. Structure Implementations (structure)
**Impact:** HIGH
**Description:** Detailed implementation guidance for specific data structures commonly needed in internal tooling. Each entry covers when to use it, the interface, implementation in Go and TypeScript, and performance characteristics.

## 3. Language Performance (lang)
**Impact:** MEDIUM-HIGH
**Description:** Language-specific performance characteristics for Go and TypeScript/JavaScript that affect data structure choice and implementation — memory layout, concurrency primitives, runtime optimizations.

## 4. Fundamentals Reference (fundamental)
**Impact:** MEDIUM
**Description:** Comprehensive reference of foundational data structures — arrays, lists, trees, graphs, hash structures — with complexity characteristics and typical use cases.
